# Next Feed

A tiny, mobile-first newborn feeding timer/tracker.

## Run locally
Open `index.html` in a browser.

## Put it online for free
Upload these files to a GitHub repository and enable GitHub Pages. Then open the resulting site on your phone and use **Add to Home Screen**.

## Notes
- Data is stored locally in the browser with localStorage.
- No account or server is required.
- The app is a timing/record-keeping tool, not medical guidance.
